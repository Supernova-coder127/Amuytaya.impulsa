"Amuyt'aya.impulsa"

-What is it?:
An educational guidance website with a single purpose: to reduce the difficulty of accessing opportunities for Peruvian students, developed to provide information about 
scholarships and encourage access to academic opportunities.

-How I built it:
The project was built using HTML, Tailwind CSS for the designs, and GitHub Pages for creating the link.

-How to run it:
The page currently does not require registration. To test it:
A. Open the page link: https://supernova-coder127.github.io/Amuytaya.impulsa/
B. Review the main interface.
C. Click the interactive button to open a window on the same page with the currently available scholarships or scroll to the bottom and click the 'Instagram' button to 
be redirected to the page's account.
